Supported question formats

Every question needs four options and a correct answer. JSON uses answer indexes 0–3. CSV and text use A–D.

CSV header:

question,A,B,C,D,answer,explanation

Plain text (leave a blank line between questions):

1. What is 2 + 2?
A) 1
B) 2
C) 3
D) 4
Answer: D
Explanation: 2 + 2 = 4.

HTML supports embedded JSON in a script with type="application/json", question blocks as shown below, or the plain-text format above inside HTML. HTML mocks like OWS are also supported when they contain a Q array of [question text, four options, correct answer index 0–3] using double-quoted JSON data. Uploaded scripts are never run. Other script-generated formats and scanned documents cannot be imported.

<div class="question" data-answer="D">
  <h3>What is 2 + 2?</h3>
  <ol><li>1</li><li>2</li><li>3</li><li>4</li></ol>
  <p class="explanation">2 + 2 = 4.</p>
</div>
